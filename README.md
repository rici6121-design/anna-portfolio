# Анна Кожевникова — портфолио

Одностраничный сайт с видео по скроллу (hero + контакты) и ноутбуком с кейсами.

## Как открыть

1. Скачайте архив `anna-portfolio.zip`.
2. Распакуйте папку `site`.
3. Откройте `index.html` локально **через простой сервер** (видео не всегда грузятся с `file://`):

```bash
cd site
python3 -m http.server 8080
```

Откройте http://localhost:8080
